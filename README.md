# Nw

An iOS-styled fork of [Aniyomi](https://github.com/aniyomiorg/aniyomi) — anime & manga,
with a left navigation rail, a Home feed ("Continue Watching" + "New Episodes"),
a clean system-blue theme and big rounded corners.

> **Note:** this app ships with no sources, just like Aniyomi.
> You add extensions in-app; what you stream is up to you.

## Get the app

1. Go to the **Actions** tab → **Build Nw APK** → latest run.
2. Download the `Nw-APK-<sha>` artifact and install `Nw-arm64-v8a.apk`
   (or `Nw-universal.apk`).
3. Enable "Install unknown apps" for your browser when Android asks.

The APK is signed with the repo's own key, so new builds install right over old ones.
